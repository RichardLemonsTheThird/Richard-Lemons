### [FrameCheck — PC Gaming Performance Platform](https://github.com/RichardLemonsTheThird/framecheck)

An independent web project that matches PC hardware and game settings against reviewed community benchmark results. Currently in active development with a limited, access-controlled beta.

- Matches CPU, GPU, memory, resolution, and rendering settings to benchmark data
- Displays average FPS, 1% lows, sample counts, and confidence levels
- Distinguishes rendered FPS from displayed FPS when frame generation is enabled
- Supports community submissions with screenshots, videos, and result files
- Includes private administrator review, moderation history, and hardware compatibility checks

**Core stack:** HTML, CSS, vanilla JavaScript, Supabase Postgres, Supabase Auth and Storage, Edge Functions, and Cloudflare Turnstile.
